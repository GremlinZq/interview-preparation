# Страница шпаргалок для собеседований

## Цель

Создать локальную русскоязычную HTML-страницу для последовательного разбора тем к собеседованию. Первый раздел посвящён HTTP и HTTPS; новые темы позднее добавляются в ту же навигацию и структуру контента.

## Структура

- Слева находится закреплённая навигация с названием проекта и крупными ссылками на подразделы HTTP/HTTPS.
- Справа материал идёт сверху вниз: вопрос, короткий ответ, анимированная схема обмена, ключевые тезисы, подробности и следующие вопросы. Парные примеры запроса и ответа могут стоять рядом на широком экране.
- На узких экранах навигация превращается в верхнюю горизонтальную панель, а контент занимает всю ширину.

## Визуальное направление

Интерфейс выглядит как компактный современный технический конспект: тёмно-синяя навигация, светлый фон с инженерной сеткой, янтарный и бирюзовый акценты, карточки примеров и одна анимация движения HTTP-пакета. Основной учебный текст имеет размер 17–18px, код — 15–16px; заголовки и вертикальные отступы остаются выразительными, но не вытесняют материал за пределы первого экрана.

## Техническое решение

- Семантический `index.html` с якорями для навигации.
- Отдельный `styles.css` для сетки, адаптивности и состояний элементов.
- Небольшой `script.js` для подсветки активного подраздела при прокрутке и текущего года в подвале.
- Никаких сборщиков, пакетов и сетевых зависимостей; страницу можно открыть напрямую или через локальный HTTP-сервер.

## Проверка

- Убедиться, что все три файла доступны через локальный сервер.
- Проверить основные семантические элементы и соответствие якорей разделам.
- Проверить отсутствие синтаксических ошибок JavaScript.
- Открыть страницу во встроенном браузере для визуального просмотра.
